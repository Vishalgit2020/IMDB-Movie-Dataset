# IMDB-Movie-Dataset

This project involves exploratory data analysis on the IMDb Movie Dataset using Python libraries such as Pandas, Seaborn, and Matplotlib. The goal is to uncover meaningful insights about movies such as their ratings, genres, revenues, and runtimes.

Tools & Technologies:

Python
Pandas for data manipulation
Seaborn & Matplotlib for data visualization

Key Insights Extracted:

Top 10 Rows: Provides an initial look at the dataset structure and content.
Dataset Shape: Total of rows and columns identified to understand the dataset size.
Null & Duplicate Check: Checked for missing and duplicate data to ensure data quality.
Long Runtime Movies: Identified movies with a runtime of 180 minutes or more.
Top 10 Rated Movies & Directors: Listed highest-rated films and their directors.
Top 10 Revenue Movies: Displayed most commercially successful movies.
Most Popular Movie: Determined by the highest revenue generated.
Action Movie Count: Counted how many movies fall under the “Action” genre.
Genre Analysis: Visualized top genres across the dataset.
Rating Distribution: Showed how ratings are distributed among the movies.
Revenue vs Rating Correlation: Analyzed if higher ratings relate to higher revenue.
